# SQL Importing Exporting company analysis
an analysis for analyzing company performance by analyzing sales and collection timeline 
the project aim to get the following KPIs:
1- important measures:
-	 total sales value
-	total cost
-	total sales qty
-	margin
2-	percentage of cost of the shipment for each shipment
3-	top 10 customers consumption in qty
4-	sales rep. performance by collected value
5- stock lead time and collection delay
